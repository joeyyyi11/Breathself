-普通css不能用单行注释 //，得用块注释/**/。
    <style scoped>          → 纯 CSS
    <style lang="scss" scoped> → 才能用 // 和嵌套
-增加z-index，层级遮挡关系，确保按键一直在最上方，不被动画遮挡而不能点。
-   src/styles/
  variables.css   → 颜色、间距等变量（--color-green-accent）
  base.css        → 全局基础样式
  components.css  → 通用按钮 .btn、.btn-ghost 等

    src/views/BreathView.vue  → 只有这个页面用的样式（scoped）
    src/components/BreathOrb.vue → 只有圆球用的样式（scoped）

    全站按钮、输入框——components.css
    颜色、间距变量——variables.css
    某个页面/组件独有——该 .vue 的 <style scoped>

-：启用“Hash 模式”：会给url地址加上“#”，处理逻辑变化。尤其是因为没有后端服务端啥的，这就是个静态网页；
  只提供固定文件环境，也就是没有后端来动态生成页面也没有服务端的路由逻辑。
  现在我们的路由时直接在浏览器客户端中发生的。而服务端路由需要新建http请求才返回对应的页面数据
-单页应用：现在用的
  路由并不是“真正的服务器页面跳转”，而是“根据 URL 显示不同组件”。
  没有刷新整个网页，而是替换了显示的组件。
  服务器端不需要处理路由，只需要返回 HTML 文件。
